# EEPZ - Employee Engagement Platform Zone

A modern employee engagement platform built with React, Vite, and Bootstrap 5.

## 🚀 Features

- ✅ Role-based authentication (Admin, HR, Department Head, Manager, Employee)
- ✅ Two-factor authentication (2FA)
- ✅ First-time login password change
- ✅ Leadership management module
- ✅ Responsive design with Bootstrap 5
- ✅ Mock API (No backend required for testing)
- ✅ Full-screen optimized layouts
